今日も使う「図形を1つ描く道具」（drawShape）

第2回で作った drawShape 関数は今日もそのまま使う。type（種類）を変えれば、いろいろなジオメトリを描ける。今日はここを掘り下げる。

JavaScript
const group = document.querySelector('#group');

function drawShape(type, x, y, z, color, size) {
  const el = document.createElement(type);
  el.setAttribute('position', `${x} ${y} ${z}`);   // 位置 = x・y・z座標（今日の主役）
  el.setAttribute('color', color);
  el.setAttribute('scale', `${size} ${size} ${size}`);
  group.appendChild(el);
}
  • 今日の前半は type を 'a-box' 以外（'a-cylinder'・'a-torus' など）に変えて、図形の種類を増やす
  • 今日の後半は、この position の x・y・z を「データ」として読み取り・記録する

A-Frame 基本ジオメトリ図鑑：空間をつくる部品をそろえる

ジオメトリ（プリミティブ）とは

  • ジオメトリ＝図形の「形」。A-Frameには、最初から使える基本図形（プリミティブ）が用意されている

ジオメトリの属性で「形」を自在に変える

同じ図形でも、属性を変えれば別の形になる

  • 各ジオメトリには、形を決める固有の属性がある（半径・高さ・太さなど）
  • 属性は 図形.setAttribute('属性名', 値)、またはHTMLに 属性名="値" で書く
  • 長さ・半径の単位はすべてメートル（m）。radius="0.5" は半径50cmの意味

図形ごとの「形を決める属性」

図形形を決める主な属性
a-boxwidth（幅）・height（高さ）・depth（奥行き）
a-sphereradius（半径）
a-cylinderradius（半径＝太さ）・height（高さ＝長さ）
a-coneradius-bottom（下の半径）・radius-top（上の半径）・height
a-torusradius（輪の大きさ）・radius-tubular（チューブの太さ）
a-ringradius-inner（内側の半径）・radius-outer（外側の半径）
a-planewidth（幅）・height（高さ）
a-octahedron ほか多面体radius（大きさ）

※ 属性名はすべて公式ドキュメントに載っている。「a-frame 図形名」で検索 → 公式を見るクセをつけよう。

JavaScriptで属性を細かく設定する道具（drawGeo）

drawShape は scale で大きさを変えたが、今度は図形ごとの属性をそのまま渡す道具を作る。extra に「属性のまとまり（オブジェクト）」を渡すのがポイント。

JavaScript
// 種類・位置・色 ＋ 図形ごとの属性（extra）を渡して1つ描く道具
function drawGeo(type, x, y, z, color, extra) {
  const el = document.createElement(type);
  el.setAttribute('position', `${x} ${y} ${z}`);
  el.setAttribute('color', color);
  // extra の中の属性を1つずつ設定する（例: {radius: 0.5, height: 2}）
  for (const key in extra) {
    el.setAttribute(key, extra[key]);
  }
  group.appendChild(el);
}

// 使い方：細い高い円柱／太い浮き輪
drawGeo('a-cylinder', -2, 1, -5, 'skyblue', { radius: 0.3, height: 3 });
drawGeo('a-torus',     2, 1, -5, 'gold',   { radius: 1, 'radius-tubular': 0.3 });
  • extra＝図形ごとの属性をまとめたオブジェクト（第2回④の復習）。{ radius: 0.3, height: 3 } のように書く
  • 属性名に -（ハイフン）が入るもの（radius-tubular など）は 'radius-tubular' とクォートで囲む
  • for (const key in extra)＝オブジェクトの中身を1つずつ取り出して設定する書き方

進め方（第2回と同じ：組み立て式）

  • 課題ごとに部品を配る。空欄 ____ を埋めて、1か所ずつ変えて再読み込み
  • 数値はどんどん変えてOK。「動いた！」「形が変わった！」を楽しむ
  • つまったら details（つまったら：完成コードを見る）を開く

標準課題 std3-2：属性を変えて「自分だけの形」を作る

同じ a-cone でも、radius-bottom や height を変えれば、ずんぐりにも・とがった形にもなる。extra（属性のオブジェクト）を変えて、形の変化を観察する。

部品（空欄は2か所）

JavaScript
// 細くて高い円柱
drawGeo('a-cylinder', -3, 1.5, -5, 'skyblue', { radius: ____, height: 3 });  // ★空欄1: 細く（小さい半径）★

座標系と位置データ：x・y・z の意味を体で覚える

ここからが「位置をデータとして読む」章（シラバス第6回）

  • position="x y z" の3つの数は、ただの置き場所ではなく 3次元の座標データ
  • x・y・zがそれぞれどの向きかを正しく理解すると、図形を狙った場所に置ける
  • この座標が、後の回の「ユーザがどこにいたか」という位置ログとまったく同じ形

A-Frameの座標系：3つの向き（右手系）

A-Frameは画面の中央（原点 0 0 0）を基準に、3つの方向に数が伸びる。自分がカメラの位置から前を見ている、と考える。

軸＋（プラス）の向きイメージ / 主な使いどころ
x右（＋x） ／ 左（−x）左右の位置。横ならび
y上（＋y） ／ 下（−y）高さ。床は y=0、宙に浮かせるなら ＋y
z手前＝自分の方（＋z） ／ 奥＝画面の中（−z）奥行き。図形を前に出すには z をマイナスに（例 -5）

覚え方

  • x＝右、y＝上はグラフと同じ。新しいのは z＝奥行き
  • これまで図形を z=-3 や z=-5 に置いたのは、z をマイナスにして「画面の奥（前方）」に出すため
  • 長さの単位はメートル（m）。position="1 1.6 -3" ＝「右に1m・高さ1.6m・奥に3m」
図解：原点(0,0,0)から伸びる3本の軸

次の課題（std3-3）では、この3本の軸を細長い箱で実際に作って、座標の向きを目で確かめる。

■ x軸（赤） ＝ 左右に伸びる　position の1つ目
■ y軸（緑） ＝ 上下に伸びる　position の2つ目
■ z軸（青） ＝ 前後に伸びる　position の3つ目

位置だけじゃない：rotation（回転）と scale（拡大）も x・y・z

  • rotation="x y z"＝各軸まわりの回転角（単位は度）。rotation="0 45 0" ＝ y軸まわりに45度回す（左右を向く）
  • scale="x y z"＝各軸方向の拡大率。scale="2 1 1" ＝ 横にだけ2倍に伸ばす
  • 位置・回転・拡大、すべてが x・y・z の3つ組。座標の考え方は全部に通じる

標準課題 std3-3：x・y・z 軸を色分けして作る（座標を体で覚える）

細長い箱を3本作り、x軸＝赤・y軸＝緑・z軸＝青で表す。各軸の position と scale を変えて、3方向に伸ばす。座標の向きが目でわかるようになる。

部品（drawGeo 入りの土台に書く・空欄は2か所）

JavaScript
// 原点に小さな白い球（基準点 0,0,0）
drawGeo('a-sphere', 0, 0, -4, 'white', { radius: 0.15 });

// x軸（赤）= 横に伸ばす
drawGeo('a-box', 0, 0, -4, 'red',   { width: 4, height: 0.08, depth: 0.08 });

// y軸（緑）= 縦に伸ばす
drawGeo('a-box', 0, 0, -4, 'lime',  { width: 0.08, height: ____, depth: 0.08 });  // ★空欄1: 縦に4m★

// z軸（青）= 奥行き方向に伸ばす
drawGeo('a-box', 0, 0, -4, 'skyblue', { width: 0.08, height: 0.08, depth: ____ });  // ★空欄2: 奥行きに4m★

組み立てチャレンジ

  • 空欄1：y軸（緑）を縦に伸ばす高さ（4）。height を大きくすると上下に伸びる
  • 空欄2：z軸（青）を奥行きに伸ばす長さ（4）。depth が前後方向
  • できたら視点をドラッグで回し、赤＝左右・緑＝上下・青＝前後を確かめる

位置を「データ」として取得・記録し、測る

座標を「読む・ためる・測る」3ステップ

  • ① 読む：図形の position を getAttribute で取り出す → {x, y, z} が手に入る
  • ② ためる：取り出した位置を配列に記録する → 位置データの「表」になる
  • ③ 測る：表をもとに距離や重心（平均位置）を計算する＝統計の第一歩

① 位置を読む：getAttribute で座標を取り出す

setAttribute（設定する）の反対が getAttribute（取り出す）。position を取り出すと、{x, y, z} のオブジェクトが返ってくる。

JavaScript
const el = document.createElement('a-box');
el.setAttribute('position', '1 2 -3');

const p = el.getAttribute('position');   // 位置を取り出す
console.log(p);       // → {x: 1, y: 2, z: -3}（オブジェクト＝第2回④）
console.log(p.x);     // → 1（ドットで取り出す）
console.log(p.z);     // → -3

これが「1件の位置データ」

{x: 1, y: 2, z: -3} は、第2回で学んだオブジェクト（1レコード）そのもの。第11回の行動ログ {時刻, x, y} とまったく同じ形。図形の位置 ＝ データ1件。

② 位置をためる：配列に記録して「表」にする

図形を作るたびに、その位置を配列に push（追加）すると、位置データの一覧（表）ができる。これが CSV・ログの正体。

JavaScript
const records = [];   // 位置をためる空の配列

for (let i = 0; i < 5; i++) {
  const x = i - 2;
  drawGeo('a-sphere', x, 1, -5, 'gold', { radius: 0.3 });
  records.push({ x: x, y: 1, z: -5 });   // 位置を1件ためる
}

console.table(records);   // → 表の形でConsoleに出る（見やすい！）
  • 配列.push(値)＝配列の末尾に1件追加する命令
  • console.table(配列)＝オブジェクトの配列を表形式でConsoleに表示（行と列で見える）
  • この records が、まさに位置データのテーブル。次はこれを使って距離や重心を測る

標準課題 std3-4：図形の位置を取得して記録し、表にする

図形を円形に並べながら、その位置を records 配列にためて、console.table で表示する。「描く」と同時に「位置データを取る」のがポイント。

  • 空欄に、図形に渡したのと同じ x と z を入れる（変数名をそのまま書く）
  • 保存 → 開く →「検証」→「Console」に8行の表が出れば成功

標準課題 std3-5：距離と重心（平均位置）を計算する

記録した位置データから、2点間の距離と、全体の重心（平均位置）を計算する。これは統計の「平均」「ばらつき」そのもの。

図解：2点間の距離の公式（3D版のピタゴラス）

2点 A(x1,y1,z1) と B(x2,y2,z2) の距離は、各軸の差を2乗して足し、ルートを取る。

距離 ＝ Math.sqrt( (x1−x2)² ＋ (y1−y2)² ＋ (z1−z2)² )

部品（std3-4 の records の後ろに書く・空欄は2か所）

JavaScript
// (A) 1件目と2件目の距離を測る
const a = records[0];
const b = records[1];
const dx = a.x - b.x;
const dy = a.y - b.y;
const dz = a.z - b.z;
const dist = Math.sqrt(____);   // ★空欄1: dx・dy・dz の2乗の和★
console.log('1件目と2件目の距離:', dist);

// (B) 全部の位置の重心（平均位置）を計算する
let sx = 0, sy = 0, sz = 0;
for (let i = 0; i < records.length; i++) {
  sx += records[i].x;    // x を全部たす
  sy += records[i].y;
  sz += records[i].z;
}
const n = records.length;
const center = { x: ____, y: sy / n, z: sz / n };   // ★空欄2: x の平均★
console.log('重心（平均位置）:', center);

// 重心の場所に赤い球を置いて、目で確認する
drawGeo('a-sphere', center.x, center.y, center.z, 'red', { radius: 0.25 });

組み立てチャレンジ

  • 空欄1：dx・dy・dz をそれぞれ2乗して足す式（dx*dx + dy*dy + dz*dz）
  • 空欄2：x の平均（合計 sx ÷ 件数 n）
  • うまくいくと、円の中心あたりに赤い球が出る（重心＝平均位置）。Consoleにも距離と重心の数値が出る
つまったら：完成コードを見る 
JavaScript
const a = records[0], b = records[1];
const dx = a.x - b.x, dy = a.y - b.y, dz = a.z - b.z;
const dist = Math.sqrt(dx*dx + dy*dy + dz*dz);
console.log('1件目と2件目の距離:', dist);

let sx = 0, sy = 0, sz = 0;
for (let i = 0; i < records.length; i++) {
  sx += records[i].x; sy += records[i].y; sz += records[i].z;
}

空欄1＝dx*dx + dy*dy + dz*dz、空欄2＝sx / n。円形に並べた点の重心は、円の中心（おおよそ x≈0, z≈-5）になる。

これが統計につながる

  • 重心＝平均。データの「代表値」を1つの座標で表したもの（第13回の平均と同じ計算）
  • 各点から重心までの距離を平均すると、データの「ばらつき（散らばり具合）」になる＝分散・標準偏差の素地
  • 今は図形の位置だが、第11〜14回では行動データの分布を、同じ計算で分析する
