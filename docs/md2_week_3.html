DOMで図形を作る3ステップ（第2回の復習）

  • ① 作る：document.createElement('a-sphere')
  • ② 設定する：図形.setAttribute('属性', 値)（位置・色・大きさ）
  • ③ 入れる：group.appendChild(図形) で空間に追加
HTMLの書き方：「デザイン」と「ロジック」を分け、<script> を書く場所にこだわる

A-FrameのHTMLは、大きく2つの部分に分けて考えると迷わない。

① デザイン（見た目・構造）
<a-scene> の中のタグ（a-sky・a-plane・a-entity）。「何を置くか」を書く
② ロジック（処理）
<script> の中のJavaScript。「どう作るか・動かすか」を書く

<script> は </a-scene> の後、</body> の直前に書く

HTML
<body>
  <!-- ① デザイン：何を置くか（先に書く） -->
  <a-scene>
    <a-sky ...></a-sky>
    <a-entity id="group"></a-entity>
  </a-scene>

  <!-- ② ロジック：どう作る・動かすか（デザインの後に書く） -->
  <script>
    const group = document.querySelector('#group');  // ← 上の #group を探す
    // ... 図形を作る処理 ...
  </script>
</body>

なぜ「デザイン → ロジック」の順なのか

  • ブラウザはHTMLを上から順に読む。<script> を先に書くと、まだ <a-entity id="group"> が作られていない
  • その状態で document.querySelector('#group') を呼ぶと見つからず（null）エラーになる
  • だからデザイン（要素）を先に置き、ロジック（script）を後に置く。「材料をそろえてから料理する」イメージ

標準課題 std3-1：for文で N 個のスフィアを出す

個数を const で決め、for 文でその数だけスフィアを横に並べる。index.html として保存 → ブラウザで開く。

土台HTML（★の部分だけ空欄）

HTML
<!DOCTYPE html>
<html>
  <head>
    <script src="https://aframe.io/releases/1.7.1/aframe.min.js"></script>
  </head>
  <body>
    <a-scene>
      <a-sky color="#111"></a-sky>
      <a-plane rotation="-90 0 0" width="30" height="30" color="#1a1a1a"></a-plane>
      <a-entity id="group"></a-entity>
    </a-scene>

    <script>
      const group = document.querySelector('#group');   // 図形を入れる場所
      const N = 10;                                   // 出す個数（const=変えない値）

      for (let i = 0; i < ____; i++) {              // ★空欄1: N 回くりかえす★
        const ball = document.createElement('a-sphere');  // ① 作る
        ball.setAttribute('position', `${i - 4.5} 1.5 -5`); // ② 位置（横に並べる）
        ball.setAttribute('radius', 0.4);
        ball.setAttribute('color', ____);                 // ★空欄2: 好きな色（文字列）★
        group.appendChild(ball);                          // ③ 空間に追加
      }
    </script>
  </body>
</html>

▲ 実行結果（Webブラウザ）：空欄を埋めて開くと、金色のスフィアが横に10個ならぶ

組み立てチャレンジ

  • 空欄1：N 回くりかえす条件（i < N）
  • 空欄2：スフィアの色を文字列で（例 'gold' や '#4FC3F7'）
  • できたら N を 5 や 20 に変えて、個数が変わることを確認する
つまったら：完成コード（scriptの中だけ）を見る 
JavaScript
const group = document.querySelector('#group');
const N = 10;
for (let i = 0; i < N; i++) {
  const ball = document.createElement('a-sphere');
  ball.setAttribute('position', `${i - 4.5} 1.5 -5`);
  ball.setAttribute('radius', 0.4);
  ball.setAttribute('color', 'gold');
  group.appendChild(ball);
}

空欄1＝N、空欄2＝'gold'。i - 4.5 で中央そろえ（i=0→-4.5, i=9→4.5）。金色の球が10個ならぶ。

座標リストを読み込んで、1つのスフィアを動かす

アニメーションの正体＝「位置を少しずつ変える」

  • 座標のリスト [[x, y], [x, y], …] を用意する（各要素＝あるコマの位置）
  • setInterval で一定時間ごとに次のコマへ進め、スフィアの position を書きかえる
  • これを速く繰り返すと、動いて見える＝アニメーション
パラパラ漫画と同じ。少しずつ位置をずらした絵を、速くめくると動いて見える。今日は「絵」の代わりに「座標」をめくる。

setInterval：一定時間ごとに処理をくりかえす

「◯ミリ秒ごとに、この処理をして」を登録する命令。アニメーションの心臓部。

JavaScript
let i = 0;
setInterval(function () {   // 300ミリ秒ごとに動く
  console.log(i);
  i = i + 1;
}, 300);              // ← この 300 が「間隔（ミリ秒）」。小さいほど速い
  • 第2引数の 300＝間隔（ミリ秒）。100 にすると3倍速く動く
  • くりかえすたびに i を1増やして、次のコマに進めるのがコツ

実際にコンソールで確かめる完成HTML

下を count.html などで保存 → ブラウザで開く → 右クリック →「検証」→「Console」を見ると、0, 1, 2… と増えていく。

HTML
<!DOCTYPE html>
<html>
  <body>
    <script>
      let i = 0;
      setInterval(function () {   // 300ミリ秒ごとに動く
        console.log(i);
        i = i + 1;
      }, 300);
    </script>
  </body>
</html>

▲ 実行結果（ブラウザのConsole）：300ミリ秒ごとに 0, 1, 2, 3… と表示される

標準課題 std3-2：座標リストでスフィアを動かす

points というリストに沿って、1つのスフィアを動かす。各要素は [x, z]（横位置・奥行き）。setInterval で次々に位置を書きかえる。

土台HTML（★の部分だけ空欄）

HTML
<!DOCTYPE html>
<html>
  <head>
    <script src="https://aframe.io/releases/1.7.1/aframe.min.js"></script>
  </head>
  <body>
    <a-scene>
      <a-sky color="#111"></a-sky>
      <a-plane rotation="-90 0 0" width="30" height="30" color="#1a1a1a"></a-plane>
      <a-sphere id="ball" radius="0.4" color="tomato"></a-sphere>
    </a-scene>

    <script>
      const ball = document.querySelector('#ball');

      // 座標のリスト（各要素 = [x, z] = 横位置・奥行き）
      const points = [
        [-4, -6], [-2, -5], [0, -6], [2, -7], [4, -6], [2, -5], [0, -4], [-2, -5]
      ];

      let i = 0;
      setInterval(function () {
        const p = points[i % points.length];    // 今のコマの [x, z]（リストを循環）
        const x = p[0];
        const z = p[1];
        ball.setAttribute('position', ____);   // ★空欄1: `${x} 1 ${z}` の形で位置を書きかえ★
        i = ____;                             // ★空欄2: 次のコマへ（i を1増やす）★
      }, 300);
    </script>
  </body>
</html>

▲ 実行結果（Webブラウザ）：赤い球が points の座標をたどって動く（画像は途中の1コマ）

組み立てチャレンジ

  • 空欄1：位置を `${x} 1 ${z}`（高さは1で固定）の形で setAttribute に渡す
  • 空欄2：次のコマへ進める（i + 1）
  • できたら points に自分で座標を足す／300 を 100 にして速くしてみる
つまったら：完成コード（scriptの中だけ）を見る 
JavaScript
const ball = document.querySelector('#ball');
const points = [[-4,-6],[-2,-5],[0,-6],[2,-7],[4,-6],[2,-5],[0,-4],[-2,-5]];
let i = 0;
setInterval(function () {
  const p = points[i % points.length];
  const x = p[0], z = p[1];
  ball.setAttribute('position', `${x} 1 ${z}`);
  i = i + 1;
}, 300);

空欄1＝`${x} 1 ${z}`、空欄2＝i + 1。赤い球がリストの座標をたどって動き続ける。

ここが今日のキモ

points は「1つの点が動いた記録＝軌跡データ」。この後は、この points がCSVから読み込んだ実データに変わり、点が23個に増えるだけ。仕組みはまったく同じ。

pandasでサッカーCSVの中身を見る

pandas（パンダス）とは ─ 表データを扱うPythonの定番ライブラリ

  • pandasは、CSVやExcelのような表（テーブル）データを、読み込み・確認・集計・分析するためのPythonライブラリ。データサイエンスの現場で最もよく使われる道具の1つ
  • 読み込んだ表は DataFrame（データフレーム）という形になる。行＝1件のデータ、列（カラム）＝項目（今回なら frame・team・id・x・y）
  • 1つの列だけを取り出したものは Series（シリーズ）と呼ぶ（例 df['x']）
  • いきなり可視化せず、まず「何行・何列あるか」「どんな値か」を確かめるのがデータ分析の第一歩

フィールド座標 → A-Frame座標への変換

CSVの座標はフィールドの実寸（105m×68m）。そのままだと大きすぎるので、1/5に縮小し、少し奥（-14）へずらして配置する。高さ y は地面すれすれの 0.6 で固定。

JavaScript
const SCALE = 0.2;      // 1/5に縮小
const ZOFF  = -14;      // 全体を奥へずらす

// フィールドの (x, y) を、A-Frameの位置に変換して図形に設定する
function place(el, x, y) {
  const sx = x * SCALE;
  const sz = -y * SCALE + ZOFF;   // フィールドのy → 奥行き(z)へ
  el.setAttribute('position', `${sx} 0.6 ${sz}`);
}
  • フィールドの x（左右）→ A-Frameのx、y（前後）→ A-Frameのz（奥行き）
  • 第1回で使った position の x・y・z の考え方の応用。上から見おろすと、フィールドの平面がそのまま見える

CSVを反映して、23個をアニメーションさせる

やることは std3-2 とまったく同じ ── 点が23個に増えるだけ

  • 準備：23個の球を1回だけ作る（毎コマ作り直さない）。team-id をキーにして覚えておく
  • 再生：setInterval でコマ番号 f を1つずつ進め、そのコマの23件の位置を書きかえる
  • コマごとにデータを分けておくと速い（byFrame[f] ＝ f コマ目の23件）

標準課題 std3-5：全コマを再生してアニメーションにする

std3-4のHTMLの <script> 内、loadCSV(...).then(...) の中身を、下のアニメーション版に置きかえる（place・colorOf・loadCSV はそのまま使う）。

部品（空欄は2か所）

JavaScript
loadCSV('soccer.csv').then(function (rows) {

  // (A) コマごとにデータを仕分ける： byFrame[f] = そのコマの23件
  const byFrame = {};
  rows.forEach(function (r) {
    if (!byFrame[r.frame]) byFrame[r.frame] = [];
    byFrame[r.frame].push(r);
  });
  let maxFrame = 0;                    // 最後のコマ番号を探す（=5399）
  rows.forEach(function (r) { if (r.frame > maxFrame) maxFrame = r.frame; });

  // (B) 23個の球を「1回だけ」作り、team-id をキーに覚える
  const ents = {};
  byFrame[0].forEach(function (r) {
    const el = document.createElement('a-sphere');
    el.setAttribute('radius', r.team === 'ball' ? 0.2 : 0.35);
    el.setAttribute('color', colorOf(r.team));
    group.appendChild(el);
    ents[r.team + '-' + r.id] = el;      // 例: "home-7" → その球
  });

  // (C) コマを順に進めて、位置を書きかえる（=アニメーション）
  let f = 0;
  setInterval(function () {
    byFrame[f].forEach(function (r) {
      const el = ents[r.team + '-' + r.id];
      place(el, r.x, r.y);            // このコマの位置へ移動
    });
    f = ____;                          // ★空欄1: 次のコマへ。最後まで行ったら0に戻す★
  }, ____);                            // ★空欄2: 間隔ミリ秒（例 100）★
});

▲ 実行結果（Webブラウザ）：全コマを再生し、選手（青・赤）とボール（白）がデータ通りに動く（画像は途中の1コマ）

  • 空欄1：次のコマへ進め、最後（maxFrame）を超えたら0に戻す
    ヒント：(f + 1) % (maxFrame + 1) で 0→5399→0 と循環
  • 空欄2：更新間隔（100ミリ秒くらい）。小さくすると速く、大きくするとゆっくり再生
  • 成功すると、選手とボールがデータ通りに動き続ける
つまったら：完成コード（(C)の部分）を見る

let f = 0;

  byFrame[f].forEach(function (r) {
    place(ents[r.team + '-' + r.id], r.x, r.y);
  });

}, 100);

3Dモデル（glTF / glb）を Sketchfab から入手して配置する

プリミティブの次は「本格的な3Dモデル」

  • これまでは球や箱（プリミティブ）だったが、A-Frameは他の人が作った精巧な3Dモデルも読み込める
  • glTF / glb は3Dモデルの標準フォーマット（“3DのJPEG”とも呼ばれる）。.gltf（テキスト＋画像の複数ファイル）と .glb（すべてを1つにまとめたファイル）がある
  • A-Frameは両方読めるが、.glb（1ファイル）が扱いやすいのでおすすめ
  • 例えばサッカーボールの3Dモデルを置けば、std3-5の白い球を本物のボールに置きかえられる

Sketchfab でモデルを入手する手順

Sketchfab は3Dモデルの共有サイト。無料でダウンロードできるモデルも多い。

  1. sketchfab.com を開き、キーワード検索（例：soccer ball）
  2. 左の絞り込みで Downloadable（ダウンロード可）にチェック
  3. モデルのページで ライセンスを確認（多くは表示義務のある CC）。利用条件を守る
  4. Download 3D Model ボタン → glTF 形式を選んでダウンロード（.glb か .zip）
  5. .zip のときは解凍し、中の .glb ファイルを使う
  6. その .glb を、index.html と同じフォルダに置く（例：model.glb）

ライセンスに注意

ダウンロードしたモデルには作者と利用条件（ライセンス）がある。授業の課題で使う範囲にとどめ、作者名の表示（クレジット）が必要なものは Notion に明記する。再配布・商用は条件をよく確認。
