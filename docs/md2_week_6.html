2つのグループを比べると、平均値にはほぼ必ず差が出る。しかしその差は、偶然のばらつきでも出る差かもしれない。第6回は、アンケート調査で自分たちの実験データを作り、統計検定（有意差検定）を使って「その差は偶然か、意味のある差か」を確率にもとづいて判断する方法を学ぶ。

今日の合言葉：「その差は、偶然でも起きる差か？」

なぜ統計検定が要るのか ― 「平均に差がある」だけでは言い切れない

差は、偶然でも出る

2つのグループの平均を比べれば、差はほぼ必ず出る。まったく同じ授業を受けた2クラスでも、テストの平均点はピッタリ同じにはならない。問題はその差が「偶然のばらつき」の範囲か、それを超えているかである。

  • データにはばらつきがある ― 同じ人でも日によって答えは揺れるし、人によっても違う
  • サンプル数が少ないほど、偶然の差は大きく出る ― 3人の平均は簡単に偏る。1万人の平均は偏りにくい
  • だから「平均が0.5違う」という事実だけでは、「差がある」という主張にはならない

統計検定（有意差検定）とは

「もし本当は差がない（＝偶然だけ）としたら、目の前の差（かそれ以上）が出る確率はどれくらいか」を計算する道具。この確率を p値 と呼ぶ。p値が小さい＝「偶然にしては起こりにくい」＝偶然では説明しづらい、意味のある差（有意差）と判断する。

p値と有意水準 0.05 ― 判断のルールを先に決めておく

判断のルール（今日から使う型）

  • p < 0.05 → 有意差あり（偶然でこの差が出る確率は5%未満。偶然にしては起こりにくい）
  • p ≥ 0.05 → 有意差なし（偶然でも十分起こる範囲。差があるとは言えない）
  • この 0.05 を有意水準と呼ぶ。科学の世界で広く使われる慣習的な基準（分野によっては 0.01 を使う）

ありがちな誤解に注意

  • 「p ≥ 0.05 ＝ 差がないことの証明」ではない。「差があるとは言えなかった」だけ。サンプル数を増やせば検出できるかもしれない
  • 「p値 ＝ 差の大きさ」ではない。p値は「偶然らしさ」の指標。差の大きさは平均値の差そのものを見る
  • 論文では記号で書く：μ（ミュー）＝平均値、σ（シグマ）＝標準偏差。例）「実験参加者1の満足度は μ = 3.83, σ = 0.87 であった」

正規性の確認 ― シャピロ・ウィルク（Shapiro-Wilk）検定

  • 正規分布＝平均のまわりに左右対称に山ができる、いちばん「ありがち」な分布。t検定はデータが正規分布に従うことを前提にしている
  • stats.shapiro(データ) で確認。ここでは p > 0.05 なら「正規性あり」とみなす（有意差の検定とは判定の向きが逆になることに注意）
  • 正規性がないときは、値そのものではなく順位（順番）を使う検定＝ノンパラメトリック検定（ウィルコクソン、マン・ホイットニー）を使う

対応のあるT検定とウィルコクソン符号順位検定 ― 計算の発想の違い

  • 対応のあるT検定：2つの測定値の「差」を計算し、その「差の平均」がどれくらい大きいかをみる
  • ウィルコクソン符号順位検定：2つの測定値の「差」を計算し、その「差の大きさに順位」を付けて判断する（極端な値に引きずられない）

先に「動く」を確かめよう。今日の要点は判断が p値で出ること

お題：「ダイエットプログラムの前後で、体重の平均に差があるか」。同じ25人の前後の測定＝対応のあるデータ。下のコードを analysis.ipynb のセル1つに丸ごと貼って Shift+Enter。

Jupyter ── セルに丸ごと貼って実行import pandas as pd
from scipy import stats

# ① CSVを読み込んで、目で見る
df = pd.read_csv('md2w6_diet.csv')
print(df.head())
print(f'サンプル数: {len(df)}')

# ② 平均と標準偏差（μ と σ）
print(f'before の平均: {df["before"].mean():.2f} kg (SD: {df["before"].std():.2f})')
print(f'after  の平均: {df["after"].mean():.2f} kg (SD: {df["after"].std():.2f})')

# ③ 正規性の確認（Shapiro-Wilk検定。p > 0.05 なら正規性あり）
stat_b, p_b = stats.shapiro(df['before'])
stat_a, p_a = stats.shapiro(df['after'])
print(f'正規性 before: p={p_b:.4f}, after: p={p_a:.4f}')

# ④ 対応のあるt検定（対応あり × 正規性あり → 表のとおり）
t_stat, p_value = stats.ttest_rel(df['before'], df['after'])
print(f't値: {t_stat:.4f}')
print(f'p値: {p_value:.6f}')
if p_value < 0.05:
    print('→ before と after のあいだに有意差あり')
else:
    print('→ before と after のあいだに有意差なし')

対応のない2群 ― ABテストを検定する

お題：「広告Aと広告Bで、クリック数に差があるか」（ABテスト）

ある商品に対して2パターンのインターネット広告 A・B を作り、ランダムに選ばれた別々のユーザにどちらか一方を見せて、クリック数を比べる ― マーケティングの定番「ABテスト」。同じ人が両方を見るわけではないので、これは対応のないデータである。

md2w6_ab_test.csv は Group（A/B）と Clicks（クリック回数）の2列に全員分が縦に混在している。まずグループごとに取り出す必要がある。

  • df[df['Group'] == 'A'] ― Trueの行だけ、つまりグループAの行だけを選んだ表
  • df[df['Group'] == 'A']['Clicks'] ― その表から Clicks 列だけを抽出

第5回の df[df['event'] == 'move'] とまったく同じ形。「絞ってから、列を取る」。

自分たちの実験 ― 「2つを比べるアンケート」をクラスで取る

  • n が少なくて有意差が出ない：n < 20 だと本当に差があっても拾えないことが多い。「有意差なし＝差がない証明ではない」と書けば、それも正しい報告
  • 授業中に n が足りなかった：第7回までに集め足して、第7回の総合演習で仕上げてもよい

発展課題 ― 先輩にアンケート調査をする（任意）

発展課題 adv6-1：先輩にアンケート調査をして、検定まで通す（任意）

gw6-2〜std6-3 の回答者はクラスメイトだった。今度は先輩に聞く。回答者が変わると、依頼のしかたも、聞けることも変わる ― 企画から結論まで、ぜんぶ1人でやる。

手順（gw6-2 と同じ型を、1人で）

  • ① 「先輩だから答えられること」を問いにする：同じ回答者が2つを比べられるテーマを選ぶ（例）先輩が履修した科目AとB、使ってきた学習アプリAとB、キャンパスの施設AとB、1年次と2年次の忙しさ…後輩として本当に知りたいことほどよい調査になる
  • ② リッカート尺度で設計：回答率を上げる4つのポイントを押さえた依頼文つきで Google Forms を作る
  • ③ 先輩から回答を集める：サークル・ゼミ・バイト先・SA の先輩などに個別にお願いして n ≥ 20 を目標に（授業チャンネルには投稿しない。乱立は大迷惑）
  • ④ 検定 → ミニレポート：std6-3 とまったく同じ流れ（map → 記述統計 → 正規性 → 検定 → グラフ → 3部構成のレポート）

個人調査ならではの注意

  • 依頼文の質＝回答率。相手は忙しい先輩 ― 誰が・何のため・匿名か・何分かかるか、を最初の4行で伝え、お願いとお礼のことばを忘れない
  • n が集まらないのも学び。集まらなかった理由の考察（配信先・依頼文・質問の重さ）をレポートに書けば、それも立派な結果
  • 回答者の個人情報を集めない（名前・学籍番号は不要。匿名で設計する）
