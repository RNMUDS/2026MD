流れは次の3ステップ。

STEP 1 ─ 舞台をつくる
3D空間を自分で作る。HTML＋A-Frameでオブジェクト配置。（本日〜第10回）
STEP 2 ─ データを取る環境をつくる
データを自分で取る。位置・操作・時間・主観評価を記録。（第4・9・11回ほか）
STEP 3 ─ データを分析する
取ったデータを統計で分析。根拠ある結論へ。（第12〜14回）

STEP 3 の山場 ─ 分析の手法（2つ）

① 統計的検定 ─ 「差は本物か、ただの偶然か」

  • 例：条件A=3.8、B=4.2 → 0.4の差は本物？偶然の誤差？
  • 「なんとなく」ではなく、データで「有意差あり／なし」を判定

② 主観評価の定量化 ─ 感覚を数値にする

  • 「使いやすい」等の主観＝数値でないので分析不可
  • リッカート尺度（1〜5）でスコア化 → ①で検定
  • 例：「有用性はBがAより有意に高い」をデータで提示

🎯 全14回でやること（身につくスキル）

空間づくりと並行し、分析の道具を演習で習得。到達像＝集める → 整える → 図にする → 数値で語る → 差を証明。

WebXR入門：ブラウザで動く3D空間

WebXRとは

  • WebXR（Web Extended Reality）＝ブラウザでVR/AR/3Dを動かす技術の総称
  • アプリ不要。URLを開くだけで3D空間へ
  • スマホ・PC・VRゴーグルなど、同じページが多端末で動く

なぜWebXRを使うのか（本授業の立場）

  • 導入が簡単：HTMLが書ければ3D空間が作れる（= 本日体験する A-Frame）

まず：WebブラウザとWebサーバの関係

HTMLは「サーバから受け取って、ブラウザが画面に描く」もの。流れを図で押さえる。

Webサーバを立てる（一番かんたんな方法）

「サーバ」と聞くと難しそうだが、コマンド1つで自分のPCをサーバにできる。

  • ターミナルで、index.html のあるフォルダへ移動
  • サーバ起動：python3 -m http.server 8000
  • ブラウザで http://localhost:8000 を開く → ページ表示
  • 止めるとき：ターミナルで Ctrl + C

※ VS Codeの拡張「Live Server」でもOK。localhost＝自分のPC自身を指す住所。

一般的なWebサーバ構築の手段（例）

世の中の公開Webサイトは、用途に応じて次のような手段で動いている。

手段例特徴
開発・学習用（手元）python3 -m http.server ／ VS Code Live Serverすぐ起動。公開はしない
サーバソフトApache ／ Nginx定番。自分でサーバを運用
プログラムで起動Node.js（Express）／ Python（Flask）動的なページ・APIに強い

クラウド／レンタルAWS ／ Google Cloud ／ さくら・エックスサーバー本格運用。規模を自由に拡大

※ どの手段でも、「ブラウザのリクエスト → サーバのレスポンス → 表示」という基本は同じ。

A-Frame基礎：ボックスと球を表示する

A-Frameとは

  • A-Frame＝HTMLのタグで3D/WebXR空間を作れるフレームワーク
  • <a-scene>（3D空間自体）の中に <a-box> や <a-sphere> などプリミティブ（基本図形）を配置
  • 読み込みは <head> に1行追加するだけ

大事なルール：オブジェクトは <a-scene> の中に書く

3D空間に置くものは、すべて <a-scene> 〜 </a-scene> の間（中）に書く。外に書くと表示されない。

<a-scene>　← 3D空間（いれもの）
📦 <a-box>　箱
🔵 <a-sphere>　球
⬛ <a-plane>　地面
🌌 <a-sky>　背景
… 置きたいオブジェクトはすべて <a-scene> の中へ …
</a-scene>
  • <a-scene>＝3D空間という「いれもの（箱）」
  • 箱・球・地面・背景などは、すべて中に入れる（入れ子＝ネスト）
  • </a-scene> の外に書いたオブジェクトは3D空間に出てこない

最初の3D空間（コピーして開いてみよう）

HTML
<!DOCTYPE html>
<html>
  <head>
    <!-- A-Frame を読み込む（1行で必須） -->
    <script src="https://aframe.io/releases/1.6.0/aframe.min.js"></script>
  </head>
  <body>
    <a-scene>
      <!-- ボックス（箱） -->
      <a-box position="-1 1 -3" color="tomato"></a-box>
      <!-- スフィア（球） -->
      <a-sphere position="1 1.25 -3" radius="0.75" color="skyblue"></a-sphere>
      <!-- 地面と背景 -->
      <a-plane rotation="-90 0 0" width="10" height="10" color="#222"></a-plane>
      <a-sky color="#111"></a-sky>
    </a-scene>
  </body>
</html>

index.html で保存 → ブラウザで開くだけ。ドラッグで視点回転。

position（位置）と主な属性

position＝"x y z" の3数値で位置を指定。位置の数値こそ、第6回の「座標データ」。

軸意味大きくすると
x左右右へ動く（マイナスで左）
y上下上へ動く（マイナスで下）
z奥行き手前へ来る（マイナスで奥）
  • カメラは初期 z=0 付近 → オブジェクトは z をマイナス（奥）に
  • 色＝color／球の大きさ＝radius／箱の大きさ＝width・height・depth

ノート：穴埋め

  • 3D空間自体を表すタグは <a-（　　　　）> である。
  • 箱は a-（　　　　）、球は a-（　　　　）で表示する。
  • position="x y z" のうち、奥行きを表すのは（　　　　）である。

組み立て式で進めます

  • 完成形を載せるのは「最初の1つ」だけ
  • 以降は部品（パーツ）で配布 → 置く場所と順番は自分で考える
  • コピペで終わりだと身につかない。「自分で組んで、動いた！」が一番の学び
  • 詰まったら各課題のヒントを開いてOK

for文でたくさん表示する

JavaScriptとは

  • Webページに動きや処理を加えるプログラミング言語
  • HTML＝見た目の部品 ／ JavaScript＝計算・くりかえし・データ操作などの「処理」
  • 本日は <script> 〜 </script> の中にJavaScriptを書く
  • A-Frameのオブジェクトを「量産」したり、後の回でデータ取得・集計にも使う

まず：console.log でメッセージを表示

console.log( ) ＝ 開発者ツールの「コンソール」に文字や数値を出す命令。プログラムの動作確認の基本。

HTML
<script>
  console.log('こんにちは！');   // 文字を表示
  console.log(1 + 2);          // 計算結果 3 を表示
</script>
  • HTMLファイルをブラウザで開く → 右クリック →「検証」→「Console」タブを開く
  • コンソールに こんにちは！ と 3 が表示されればOK
  • 文字は '　'（クォート）で囲む。数値はクォートなしで書く

JavaScriptの基本文法（今日使う分だけ）

文法を全部は覚えない。演習で実際に使う基礎だけを押さえる。

① 変数：値に名前をつけて入れておく箱

JavaScript
const name = 'みな';   // const = あとで変えない
let count = 0;       // let = あとで変える

② 値の型：文字列 と 数値

JavaScript
'こんにちは'   // 文字列 → クォート '　' で囲む
42          // 数値 → クォートなし

③ 計算：＋ − ＊ ／

JavaScript
count = count + 1;   // count を 1 増やす

④ テンプレートリテラル：文字列に値を埋め込む（重要）

JavaScript
const i = 3;
`${i - 5} 1 -5`   // → "-2 1 -5"（位置の文字列を作れる）
  • バッククォート `　` で囲み、${ } の中に式を書くと計算結果が入る
  • for文で position を作るときに使う（部品④の空欄）

⑤ コメント：// から後ろはメモ（実行されない）

次に、同じタグを手で100個書くのは大変なので、JavaScriptのfor文 で「量産」する。for文は後の回の「たくさんの計測対象・データ点」の基礎。

for文の形

JavaScript
for (let i = 0; i < 10; i++) {
  // 中身が10回くりかえされる（i は 0,1,2,...,9）
}
  • let i = 0：カウンタの初期値
  • i < 10：条件が成り立つ間くりかえす
  • i++：1回ごとに i を1増やす

部品を組み立てて「箱を10個」を完成させよう

完成コードなし。部品①〜④を正しい場所・順番で組み立て。空欄（____）は自分で埋める。

部品① 土台のHTML（変更せず使ってOK）

JavaScript

部品④ 箱を1つ作って空間に追加（③の中括弧の中に入れる）

JavaScript

box.setAttribute('position', `____ 1 -5`);   // 空欄: i を使って横にずらす式

組み立てチャレンジ

  • 部品①を index.html という名前で保存する
  • <script> の中に、② → ③ の順で書く
  • ③の for の 中括弧 { } の中 に ④ を入れる
  • ④の空欄 ____ に、i を使って横にずらす式を入れる
    ヒント：10個が中央に広がるには、x が −5〜+4 になるとよい

JavaScript
const group = document.querySelector('#group');

  box.setAttribute('color', '#76B900');
  box.setAttribute('width', '0.6');
  box.setAttribute('height', '0.6');
  box.setAttribute('depth', '0.6');

}

標準課題 std1-3：forをもう1つ足してグリッドにする

  • いまは「横一列（x）」だけ → 縦×横の格子にする
  • forをもう1つ外側に追加し、奥行き（z）もずらす
  • 格子状の配置＝第6回「位置データの分布」につながる
  • 完成コードは伏せる。部品をヒントに組み立て

部品A 二重forのわく（x＝横、z＝奥行き）

JavaScript
for (let x = 0; x < 5; x++) {
  for (let z = 0; z < 5; z++) {
    // ★球を1つ作る（部品B）★
  }
}

部品B 球を作る（position の空欄を埋める）

JavaScript
const s = document.createElement('a-sphere');
s.setAttribute('position', `${x - 2} 1 ____`);   // 空欄: z を使って奥にずらす式
s.setAttribute('radius', '0.3');
s.setAttribute('color', `hsl(${(x * 5 + z) * 12}, 70%, 60%)`);  // 1個ずつ色が変わる
group.appendChild(s);
図解：`${x - 2} 1 ____` ＝ 変数を組み合わせて position を作る

position は 「x y z」＝半角スペース区切りの3つの数値。バッククォート `　` で全体を1つの文字列にし、${ } の中だけが計算されて数値に化ける。

`${x - 2}␣1␣____`
└ x座標（横）　└ y座標（高さ＝1で固定）　└ z座標（奥行き）
  • ${x - 2}：${ } の中は計算される。x が変わると数値も変わる（横の位置）
  • ␣1␣：${ } の外は書いた通りの文字。前後の半角スペースが「x y z」の区切り
  • ____：ここに z を使った式を入れると、奥行きの数値になる（＝今回の空欄）

代入の例（空欄に z の式を入れた後のイメージ）

xz${x - 2}できる文字列
00-2"-2 1 （zの値）"
12-1"-1 1 （zの値）"
341"1 1 （zの値）"

※ x と z の2つの変数を組み合わせるので、二重forの全マスに1個ずつ球が置ける。

組み立てチャレンジ

  • std1-2の <script> をベースに、for文を部品Aの二重に置きかえる
  • 内側に部品Bを入れて球を作る
  • 空欄 ____ に、z を使って奥（マイナス方向）にずらす式を入れる
    ヒント：手前から奥へ並べるには、z が大きいほど位置をマイナスにする
つまったら：完成した <script> の中身を見る 
JavaScript
const group = document.querySelector('#group');
for (let x = 0; x < 5; x++) {
  for (let z = 0; z < 5; z++) {
    const s = document.createElement('a-sphere');
    s.setAttribute('position', `${x - 2} 1 ${-z - 3}`);
    s.setAttribute('radius', '0.3');
    s.setAttribute('color', `hsl(${(x * 5 + z) * 12}, 70%, 60%)`);
    group.appendChild(s);
  }
}

空欄＝${-z - 3}。z が 0→4 → 奥行き −3→−7 → 5×5＝25個が格子状。

発展課題 adv1-1：for文でアート作品をつくる（自由創作・任意）

ここまでの技を全部使って、for文でたくさんのオブジェクトを配置し、自分だけのアート作品をつくる。正解はなし。見て楽しい・面白いを目指す。

使える技（組み合わせ自由）

  • オブジェクト：a-box / a-sphere / a-cylinder / a-cone / a-torus など
  • for文：1重で「並べる」／二重で「敷き詰める」
  • position の式：i や x,z を計算して、らせん・波・円・タワーなどの形に
  • 色：hsl() や i で1個ずつ変化させてグラデーション
  • 大きさ：radius や scale を i で変えて、だんだん大きく／小さく

アイデアの例

  • 色が変わるらせん階段（y を i で上げ、x,z を Math.sin/Math.cos で回す）
  • 大きさが波打つ球の絨毯（二重forで敷き詰め、radius を場所で変える）
  • 虹色のタワー（縦に積んで hsl() で色を回す）

ヒント

  • まず std1-3 のコードをコピー → 数値や式を1か所ずつ変えて反応を見る
  • Math.sin(i)・Math.cos(i) を使うと曲線・円が作れる
  • 「なぜそうした」を一言メモしておくと、後の発表で語れる
