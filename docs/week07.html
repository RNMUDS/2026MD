データ可視化の基礎 ── なぜ可視化し、そこから何を読み取るのか

最終課題に入る前に、そもそも「データを可視化する」とはどういうことかを整理しておこう。コービーの作品も、ただ点を並べたのではなく「年ごとの変化を見たい」という目的があった。ここでは なぜ可視化するのか → 何に注目して様子を見るのか → そこからインサイト（気づき）をどう見つけるのかを、順を追って説明する。

1. なぜデータを「可視化」するのか

同じデータでも、数字の羅列とグラフでは伝わり方がまったく違う。人間の脳は、数字の表を1つずつ読むのは苦手だが、位置・長さ・色・形の違いなら一瞬で比べられる。可視化とは、この「目で見て比べる力」を借りて、データを理解しやすくする作業だ。

健康診断の結果が「数値の一覧」だけだと、自分が悪いのか良いのか分かりにくい。だが「基準範囲のバーの中で、自分の値がどこにあるか」を図で示されると、一目で「ここが高い」と分かる。可視化は、データを自分ごととして理解できる形に変える。

▲ 同じ5か月分のデータ。表だと「7月が多い・8月が少ない」と気づくのに時間がかかるが、棒グラフなら瞬時に分かる。

可視化でできるようになること

  • 大量の数字を一度に把握できる ── 何百行のデータも1枚の図に収まる
  • 差・傾向・異常が一目でわかる ── 大小・増減・飛び抜けた値が見える
  • 言葉にしにくいことを共有できる ── 「なんとなく多い」を全員が同じ図で確認できる

2. 可視化して「様子を見る」── どこに注目するか

グラフは、作って終わりではない。「眺める」のではなく「読む」。次の5つの観点を持って見ると、ただの絵が「読み取れるデータ」に変わる。

観点自分への問いかけ例（Slackデータ）
傾向（トレンド）全体として増えている? 減っている?月ごとの投稿数が右肩上がり
外れ値飛び抜けた点・へこんだ点はない?ある1日だけ投稿が急増した
周期・リズム繰り返すパターンはある?毎週月曜にアクティブ数が上がる
かたより（分布）一部に集中していない?投稿の8割が数人に集中
関係（相関）2つの量は連動している?メッセージが多い日はファイルも多い

▲ 同じ1本の線でも、「全体の傾向」「繰り返すリズム」「飛び抜けた点（外れ値）」と、見る観点を変えると複数の気づきが得られる。

3. 観察から「インサイト（洞察）」を見つけるまで

可視化の本当のゴールは、きれいなグラフを作ることではない。そこから 「だから何が言えるのか・何をすべきか」という気づき＝インサイト にたどり着くことだ。インサイトは、次の流れで生まれる。

「事実」と「インサイト」はちがう

事実: 「火曜日の投稿が一番多い」── グラフを見れば誰でも言える。
インサイト: 「火曜が多いのは “週初めの定例後に共有が集中する” から。なら、その流れを他の曜日にも作れば全体が活発になる」── なぜ? だから何をする? まで踏み込んだ気づき。最終課題の「施策提案」や「工夫した点」は、この段階を狙ってほしい。

冒頭のコービーの作品で考えると

  • 観察: 若い頃はゴール下中心 → 年々、遠い位置（3P）からのシュートが増えている
  • 問い: なぜ年々ゴールから離れていったのか?
  • 仮説: 加齢で接触の多いプレーを減らし、シュート技術で勝負するようになったのでは?
  • インサイト: 「一流選手は、身体の変化に合わせてプレースタイルそのものを進化させている」── 単なるシュート位置の事実を超えた気づき

最終課題につなげると

作品を作るときは、「何を伝えたいか（目的）」→「どんな図なら様子が見えるか」→「見た人にどんな気づき（インサイト）を持ってほしいか」の順に考えると、ねらいのはっきりした作品になる。Notion の「作った目的」「設計」「施策提案／工夫した点」は、まさにこの流れを書く欄です。

CS/DS基礎: データ可視化とリテラシー

データ可視化の原則

データ可視化で最も大切なのは、「何を伝えたいか」を明確にしてから「どう見せるか」を決めることです。目的のない可視化は、ただの飾りになってしまいます。

可視化データを視覚的に表現して理解しやすくすること csv.DictReaderCSVの各行を辞書として読み込むPython標準ライブラリ アウトカム作品を見た人に生まれる気づきや行動変化 記述統計平均・最大・最小などデータの基本的な要約
料理で例えると、「誰に食べてもらうか」（受け手）と「何を味わってほしいか」（伝えたいこと）を決めてからレシピ（見せ方）を考える。高級な食材を並べても、意図がなければ美味しい料理にはならない。

グラフの種類と使い分け

グラフ適している場面例
棒グラフカテゴリ間の量の比較曜日ごとのメッセージ数
折れ線グラフ時間の経過に伴う変化月ごとのアクティブメンバー数の推移
散布図2つの数値の相関関係メッセージ数 vs ファイル数

グラフの嘘に騙されない

グラフの嘘（データリテラシー）

  • Y軸の切り取り: 0から始めない棒グラフは差を誇張する
  • スケール操作: 軸の間隔を変えると印象が変わる
  • チェリーピッキング: 都合の良い期間だけを切り取る
  • 3Dグラフ: 奥行きで面積が歪み、正確な比較ができない

データを見るとき、常に「このグラフは何を隠しているか」を考えるクセをつけましょう。

基本的なCSV読み込み（テキスト表示）

CSVファイルの先頭10行を読み込み、日付とアクティブメンバー数を画面に表示します。

Python ── sample1_basic.py
import py5
import csv

data = []
with open('DS全体のslack利用状況.csv', 'r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    count = 0
    for row in reader:
        if count >= 10:
            break
        date = row['日付']
        active = int(row['アクティブなメンバー数（日次）'])
        data.append({'日付': date, 'アクティブ': active})
        count += 1

def setup():
    py5.size(600, 400)
    font = py5.create_font('MS ゴシック', 20)
    py5.text_font(font)

def draw():
    py5.background(255)
    py5.fill(0)
    py5.text_size(18)
    py5.text("CSVデータ表示", 50, 30)
    py5.text_size(14)
    for i, row in enumerate(data):
        y = 60 + i * 25
        py5.text(f"{row['日付']}: {row['アクティブ']}人", 50, y)

py5.run_sketch()

py5 可視化パターン集 ── 「型」を真似れば作れる

「何を作ればいいか分からない」人へ。py5 での可視化は、実はたった1つの“型”の繰り返しでできています。まず共通の型を覚え、あとは下のパターンから作りたい見た目を選んで真似るだけ。各パターンに動く図とコードの骨子を付けました。コピーして数字を変えるところから始めよう。

すべての可視化に共通する「型」

どんなグラフも、結局は次の5ステップ。②マッピングと③ループ描画が心臓部です。

Python ── 共通の骨格
import py5, csv

data = [...]                         # ① CSVを読んでリストや辞書に

def setup():
    py5.size(600, 400)

def draw():
    py5.background(255)
    for i, v in enumerate(data):       # ③ ループで1つずつ
        x = py5.remap(i, 0, len(data), 50, 550)   # ② 値→画面座標
        h = py5.remap(v, 0, max(data), 0, 300)
        py5.fill(118, 185, 0)            # ④ 装飾
        py5.rect(x, 350 - h, 40, h)

py5.run_sketch()

心臓部は py5.remap() ── 「値」を「画面の位置」に変える

データの数値（例: 12人）を、そのまま画面に置くことはできません。「データの範囲」を「画面の範囲」に置き換えるのが remap。これさえ分かれば、棒の高さ・点の位置・色・角度…何にでも応用できます。

Python ── remapの使い方
# remap(変換したい値, 元の最小, 元の最大, 変換後の最小, 変換後の最大)
h = py5.remap(active, 0, 100, 0, 300)   # 人数 → 棒の高さ(px)
x = py5.remap(i, 0, len(data), 50, 550) # 何番目か → 横位置
c = py5.remap(v, 0, max(data), 0, 255)  # 値 → 色の濃さ

コツ: 高さや縦位置は「画面の下が大きい」ので、下を大きい数・上を小さい数にすると上向きグラフになります（例: remap(v, 0, max, 350, 50)）。

パターン7

アニメーション ── 時間（フレーム）で動かす

py5の強みはここ。 draw() は毎フレーム呼ばれるので、frame_count を使うと「伸びる・揺れる・流れる」動きが作れます。静止画＋これで一気に魅力が増します。

py5 ── 骨子
def draw():
    py5.background(255)
    for i, v in enumerate(data):
        # フレーム経過で 0→1 に伸びる（登場アニメ）
        grow = min(py5.frame_count / 60, 1)
        h = py5.remap(v, 0, max(data), 0, 300) * grow
        # sinで揺らすなら: y揺れ = py5.sin(py5.frame_count*0.1 + i)*10
        py5.rect(60 + i*90, 350 - h, 50, h)

使う既習知識: draw()ループ ・ frame_count ・ sin で揺らす
