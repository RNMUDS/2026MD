0-1. 関数（function）とは

自習

関数 はプログラミングの最も基本的な「部品」．「入力」を受け取り → 「処理」をして → 「出力」を返す ひとまとまり．

自動販売機 をイメージしよう．「ボタンを押す（入力）」→「中で機械が動く（処理）」→「ジュースが出てくる（出力）」．これがまさに関数の動き．「お金とボタン」が 引数，「出てくるジュース」が 戻り値．

なぜ関数を使うのか

  • 同じ処理を 何度も書かなくて済む（消費税の計算を3回書く必要がない）
  • 名前をつけて 意味を分かりやすく できる（add_tax という名前を見ただけで何の処理か分かる）
  • 修正するときも 1か所だけ直せばよい

Python の関数の書き方（基本構文）

Python ── 関数の基本形
def 関数名(引数):
    処理
    return 戻り値
  • def は define（定義する） の略．「関数を作りますよ」という宣言
  • 関数名 は半角英数字．分かりやすい名前をつける（例: add，greet）
  • (引数) は 関数に渡すデータ．無くてもよい．複数なら , で区切る
  • 関数の中身は 4スペースのインデント（字下げ）で書く
  • return で 計算結果を返す．無い場合は None（何もない）が返る

最も簡単な例

Python ── 数を2乗する関数
def square(x):
    answer = x * x
    return answer

result = square(5)
print(result)   # 25 と表示される
  • def square(x): ─ 引数 x を受け取る関数 square を 定義
  • answer = x * x ─ x を2乗して answer に入れる
  • return answer ─ answer を呼び出した側に 返す
  • result = square(5) ─ 関数 square を 呼び出し，戻り値を result に受け取る
  • print(result) ─ result（=25）を画面に表示

✅ 0-1 チェック問題

  1. 「引数」と「戻り値」を，自分の言葉で1行ずつ説明できるか？
    ▶ 答えを見る
    引数: 関数を呼び出すときに 外から渡すデータ（入力）．関数の ( ) の中に書く．
    戻り値: 関数が処理した結果として 呼び出した側に返すデータ（出力）．return の後ろに書いた値．
  2. 下のコードを実行すると何が表示されるか？答えてから実行して確認． 
    Python ── 確認問題
def triple(n):
    answer = n * 3
    return answer

print(triple(7))
    ▶ 答えを見る
    21 と表示される．
    理由: triple(7) で引数 n に 7 が入り，関数内で answer = 7 * 3 = 21 が計算され，return answer で 21 が返る．それを print が表示．
  3. def は何の英単語の略か？
    ▶ 答えを見る
    define（定義する）の略．「これから関数を定義します」という宣言．

0-2. 時系列データ（time series data）とは

自習

時系列データ は，時間順に並んだ値の列 のこと．「いつ」「いくつだった」を時間順に並べたデータ．

体温を1日3回（朝・昼・夜）測って記録した表．これは時間順に体温が並んでいるので時系列データ．SNS の毎時のフォロワー数の変化や，ゲームのスコア履歴も同じ．

身近な時系列データの例

分野時系列データの例記録間隔
天気気温・湿度・気圧1時間ごと
健康心拍数・歩数（Apple Watch）1秒〜1分ごと
経済株価・為替レートミリ秒ごと
スマホ加速度・ジャイロセンサ1/100秒ごと
地震地震計の振動1/1000秒ごと

グラフにすると分かりやすい

時系列データは 横軸=時間，縦軸=値 の折れ線グラフで可視化されることが多い．

時系列データを扱う基本ステップ

  1. 記録（センサ・システムが値を時間順に保存）
  2. 読み込み（ファイルや DB からプログラムに取り込む）
  3. 欠損・外れ値を除去
  4. 平滑化（移動平均などでなめらかにする） ← Task 3 でやる
  5. 可視化・予測・異常検知

0-3. CSV ファイルとは

自習

CSV は Comma Separated Values の略．カンマで区切られた値 がそのまま並んだテキストファイル．拡張子は .csv．

Excel の表をシンプルなテキストで保存したもの．スプレッドシートの「行」が 1行のテキスト，「列」が カンマで区切られた値 に対応する．Excel でも開けるし，メモ帳で開いて中身を直接読むこともできる．

CSV の典型的な構造

acc_y.csv の例
timestamp,AccY
0.00,-0.12
0.01,0.34
0.02,1.56
0.03,2.78
0.04,3.21
  • 1行目はヘッダー（列の名前）になっていることが多い．この例では timestamp（時刻）と AccY（Y軸加速度）
  • 2行目以降が実データ．1行が1サンプル
  • 列同士は カンマ（,） で区切る．スペースは入れないことが多い
  • 数値も文字もそのまま書く．文字列にだけ "（クオート）を付けることもある

CSV が広く使われる理由

  • シンプル: ただのテキストファイルなのでメモ帳でも見られる
  • 互換性が高い: Excel, Google Sheets, Python, R など何でも読める
  • 軽い: バイナリより容量が小さい
  • 人間も読める: 何のデータか目で見て分かる

注意：CSV のよくある罠

  • セルに カンマが含まれる文字列（住所など）は区切りと混同される
  • センサデータでは値が 欠けている行 がよくある（例: 0.06, のように空白）
  • 外れ値（極端に大きい・小さい値）も混ざることがある

    ▶ 答えを見る
    Comma Separated Values（カンマで区切られた値）
  2. CSV ファイルの 1行目 に何が書かれていることが多いか？
    ▶ 答えを見る
    ヘッダ行（列の名前）．例: timestamp,AccY のように，各列が何のデータかを示す名前が書かれている．
  3. 下の CSV は 何列 あるか？ また データ行は何行 あるか？ 
    CSV ── 確認問題
date,temperature,humidity
2026-05-01,22.5,60
2026-05-02,24.1,55

    データ行: 3行（1行目はヘッダなので除外．2〜4行目の5/1, 5/2, 5/3 の3日分）

0-4. py5 で CSV を読み取る簡易コード

自習

py5 は，グラフィック・アニメーション・インタラクションを 簡単に書ける Python ライブラリ．授業 Task 3 で UFO を動かすときに使う．まずは「py5 で CSV を読んで値を取り出すだけ」の最小コードを読んで，動きを理解しよう．

py5 の基本構造（覚えておくと楽）

Python ── py5 の最小スケッチ
import py5

def setup():
    # 最初に1回だけ呼ばれる（初期化）
    py5.size(400, 400)

def draw():
    # 毎フレーム呼ばれる（描画）
    py5.background(255)

py5.run_sketch()
  • setup() ─ プログラム開始時に 1回だけ 呼ばれる．ウィンドウサイズ設定，ファイル読み込みなどをここで
  • draw() ─ 毎秒60回ほど自動で繰り返し 呼ばれる．アニメーション描画はここで
  • py5.run_sketch() ─ スケッチ（プログラム）を 開始する ためのおまじない

処理の流れ（絵で理解）

CSV ファイルが 1行ずつの文字列リスト になり，カンマで分割 され，数値に変換 されて 蓄積 されるまでの流れ．次の図を見てからコードを読むと一気に理解しやすい．

CSV を読み取る簡易コード（解説付き）

Python ── py5 で CSV を読む最小例
import py5

# 読み込んだ AccY 値を入れる箱
values = []


def setup():
    py5.size(400, 400)

    # acc_y.csv を1行ずつテキストとして読み込む
    lines = py5.load_strings("acc_y.csv")

    # 先頭行（ヘッダー）はスキップして 2 行目から処理
    for line in lines[1:]:
        # カンマで分割して 2 つの部分にする
        parts = line.split(",")

        # 2列目（AccY）の文字列を数値（float）に変換
        value = float(parts[1])

        # values リストに追加
        values.append(value)

    # 読み込み結果を確認するための表示
    print("読み込んだ値の数:", len(values))
    print("最初の3個:", values[0], values[1], values[2])


py5.run_sketch()

1行ずつ丁寧に解説

コード意味
import py5py5 ライブラリを使えるようにする
values = []空のリストを用意．ここに数値を追加していく
py5.size(400, 400)幅400・高さ400 のウィンドウを作る
py5.load_strings("acc_y.csv")CSV ファイルを 1行ずつ文字列のリスト として読む
for line in lines[1:]:2行目から最後 まで，1行ずつ line に入れて繰り返し（[1:] は「1番目以降」の意味で，0番目のヘッダ行をスキップする）
line.split(",")1行の文字列を カンマで分割 してリストにする．例: "0.00,-0.12" → ["0.00", "-0.12"]
float(parts[1])リストの 2番目（インデックス1）の文字列を数値に変換．例: "-0.12" → -0.12
values.append(value)数値を values リストの 末尾に追加
print(...)確認のため値を表示

インデックス（番号）の数え方は 0 から

Pythonのリストは 0番目 から数える．
例: parts = ["0.00", "-0.12"] なら parts[0] が "0.00"，parts[1] が "-0.12"．
だから 2列目を取りたいときは parts[1] と書く．

欠損・外れ値が混ざっていたら？

実際のセンサデータでは 0.06, のように 値が空 の行や，数字でない文字 が紛れることがある．そのまま float() すると エラーで止まる．対策は try / except でスキップする：

Python ── 欠損行をスキップする書き方
for line in lines[1:]:
    parts = line.split(",")
    try:
        value = float(parts[1])
        values.append(value)
    except (ValueError, IndexError):
        # 数値に変換できない／列が足りない行はスキップ
        continue

→ Task 3 でも opencode に「欠損行はスキップして」と指示するとこれに近いコードが生成される．

✅ 0-4 チェック問題

  1. py5.load_strings("acc_y.csv") は 何を返す か？（型と中身）
    ▶ 答えを見る
    文字列のリスト（list of strings） を返す．リストの各要素はCSVファイルの 1行分のテキスト．
    例: ["timestamp,AccY", "0.00,-0.12", "0.01,0.34", "0.02,1.56", ...]
  2. lines[1:] の [1:] は何を意味するか？ なぜ [0:] や lines ではないのか？
    ▶ 答えを見る
    [1:] は「インデックス1から最後まで」つまり 2番目以降 を取り出すスライス．
    0番目はヘッダ行（"timestamp,AccY"）で 数値ではない ため，そのまま float() するとエラーになる．だから [1:] でヘッダをスキップする．
    [0:] や lines だとヘッダ行も処理してしまい，ValueError で落ちる．
  3. line.split(",") は何のための処理か？ 例を挙げて説明せよ
    ▶ 答えを見る
    1行の文字列を カンマで分割してリストにする 処理．CSVの各列を取り出すために使う．
    例: "0.00,-0.12".split(",") → ["0.00", "-0.12"]
  4. float(parts[1]) はなぜ 1 なのか？ 0 ではダメか？
    ▶ 答えを見る
    インデックスは 0から始まる．
    parts[0] = 1列目 = timestamp（時刻）
    parts[1] = 2列目 = AccY（加速度の値）
    今回欲しいのは 加速度の値 なので parts[1]．parts[0] だと時刻を取ってしまうのでダメ．
  5. setup() と draw() の違いを説明せよ
    ▶ 答えを見る
    setup(): プログラム開始時に 1回だけ 呼ばれる．ウィンドウサイズの設定，画像やCSVの読み込みなど 準備 をする．
    draw(): 毎フレーム（毎秒60回程度）繰り返し 呼ばれる．アニメーションの 描画 をここに書く．

バイブコーディング解説と opencode の導入

準備

2-0. バイブコーディングとは何か

解説

バイブコーディング（vibe coding） は 2025年に Andrej Karpathy が広めた呼び方．プログラミングを「文法を1行ずつ書く作業」から，「やりたいことを言葉で伝え，AIが書いたコードを読んで判断する作業」 に変える開発スタイル．

3つの基本ループ

  1. 指示: やりたいことを言葉で書く（日本語でも英語でもOK・自分が書きやすい言語で）
  2. 確認: AIが書いたコードを 読む ．分からなければ説明させる
  3. 修正: 動かなければ・期待と違えば，差分を言葉で指示
シェフ（AI）に作りたい料理を伝える役．シェフは腕の確かなプロだが，あなたは 味見係 でもある．味見をせず客に出すと事故が起きる．

なぜ必要か

  • 調査・試作・ドキュメント参照などに 圧倒的に時間を取られなくなる
  • 初学者でも 動くものを早く作れる ので学習が止まりにくい
  • 本来集中すべき 「何を作るか」「なぜ作るか」 に時間を回せる

注意点（初心者ほど大事）

1. ハルシネーション

存在しない関数名やライブラリを 堂々と書く ことがある．必ず公式ドキュメントで検索 するか，実際に実行して確認．

2. 「動いたから正しい」とは限らない

動くがロジックが間違っているコードはよくある．境界値（0・空リスト・最大値）を試して期待通りか確認．

3. 自分で書く練習を捨てない

すべて AI に書かせると 基礎力が育たない ．基礎が無いと AI の出力を 評価できなくなる ．今日の Task 1（関数の口頭確認）はその基礎．

5. 詰まったら3往復ルール

同じエラーで AI に3回プロンプトしても解決しないなら ，方針を変えるか，先生・SAに相談．

加速度センサと時系列データ: UFO横揺れアニメ＋移動平均

3-1. 加速度センサと時系列データの基礎

解説

今日のデータ acc_y.csv は スマートフォンの加速度センサ から取得したと仮定した疑似データ．データサイエンスとコンピュータサイエンスの両面から 時系列データの扱い方 を学ぶ．

加速度センサとは

  • スマホ・スマートウォッチ・自動車・地震計などに入っている
  • X / Y / Z の3軸の 加速度（m/s²） を時間ごとに記録
  • 歩数計・転倒検知・地震速報など，現実世界の挙動を数値化する基礎技術

時系列データとは

  • 「時刻」と「値」のペア が時間順に並んだデータ列
  • 典型フォーマット: CSV（カンマ区切り）．1行＝1サンプル
  • 処理パターンの基本: 読み込み → 欠損除去 → 平滑化 → 可視化
acc_y.csv（先頭5行・例）
timestamp,AccY
0.00,-0.12
0.01,0.34
0.02,1.56
0.03,2.78
0.04,3.21

なぜ加速度データはノイジーなのか

センサは 細かな振動・電気ノイズ・量子化誤差 を拾うため，値は常に小刻みに揺れる．人間が「動き」として見たい成分の上に「ノイズ」が乗った状態．→ そのまま使うとアニメが ガタガタして見づらい ので，平滑化（スムージング） が必要．

  • 縦方向は AccY の値 に応じて上下に揺れる（=横移動しながら縦揺れ）

3-3. Step B: 移動平均で「なめらか」にする

std5-2 実習

Step A の UFO はガタガタして見づらい．これを 移動平均法（moving average） でなめらかにする．移動平均は 時系列処理の最も基本的なスムージング手法．

移動平均とは（CS基礎）

連続する N点（窓幅） の値を平均する．例: values = [10, 20, 30, 40, 50]，window=3 →

[ (10+20+30)/3, (20+30+40)/3, (30+40+50)/3 ] = [20.0, 30.0, 40.0]

窓幅が大きいほど なめらか．ただし大きすぎると元の動きが消えて ぼやけた動き になる．

プロンプト例（参考・自分の言葉で書き換える）
今のコードに、AccY を移動平均（window=5）で平滑化する処理を追加してください。

- 平滑化した値を使ってUFOの縦位置を決める
- 移動平均は自前の moving_average(values, window) 関数として定義
- 画面左上に「smoothed (window=5)」のテキストを表示

動作確認ポイント

  • UFOの縦の動きが 明らかになめらか になる
  • 左→右の横移動は変わらず動く
  • クラッシュしない
  • window を 3, 11, 21 に変えてみる と動きがどう変わるか観察

移動平均が現実世界で使われる例

  • 株価チャート: 5日線・25日線・75日線
  • 気象データ: 移動平均気温で長期トレンド表示
  • センサデータ: ジャイロ・加速度・心拍数の前処理
  • 音声処理: ノイズ除去フィルタの最も簡単な形

発展課題: 自分のスマホで測ったセンサデータで 自由作品 をつくる

adv5-1

4-0. 課題の主旨

必読

授業で使った acc_y.csv は「与えられたデータ」だった．発展課題では 自分でセンサデータを集めるところから やる．

  1. スマートフォンで 加速度・ジャイロ・回転などのセンサ値を取得できるアプリ を 自分で探して インストールする．
  2. 自分の手で動かす／歩く／揺らす などして センサデータを記録 し，CSV としてエクスポート（または手作業で書き出し）する．
  3. そのデータを使って 「再現したい動き」のあるアニメーション作品 を py5 でつくる．題材は完全に自由．

標準課題の UFO のように センサ値 → 画面の動き へマッピングするのが土台．opencode（バイブコーディング）で AI に手伝ってもらってOK．

4-1. 作品例: 「夜空を飛ぶ蛍」

サンプル

イメージしやすいよう，1つだけ例を示す．これをそのまま作る必要はない ──自分のオリジナル作品を考えよう．

🪲 例: 蛍の動きをスマホで再現

▲ 蛍の動きを再現したサンプル作品．自分の作品もこのくらいの完成度を目指そう．

  • センサの取り方: スマホを手のひらに乗せ，ふらふらと不規則に揺らしながら 30〜60秒間，加速度（XYZ）を記録する．
  • マッピング: 加速度 X → 蛍の 横方向の漂い，加速度 Y → 上下のふわふわ，加速度の大きさ → 光の強さ（明滅）．
  • 背景: 真っ暗な夜空（黒〜濃紺のグラデーション）．星をいくつか点で描く．
  • 蛍: 小さな黄緑色の光の玉．中心は明るく，周囲はぼんやり光るグロー（半透明の円を重ねる）．
  • 移動平均 をかけて動きをなめらかに．蛍が ふわっと 漂う感じになる．
  • 応用: 蛍を 複数匹 出して，それぞれ少しずつ 時間をずらして 同じデータを再生 → 群れのように見える．

他のアイデア例（自分でもっと面白い題材を考えよう）:

  • 水面に落ちた葉が 波で揺れる（ゆっくり歩いて記録した加速度を使う）
  • 鳥が 羽ばたきながら飛ぶ（スマホを縦に小刻みに振る）
  • 音楽に合わせて 踊るキャラクター（スマホをリズミカルに動かす）
  • 嵐の中で 傘がひっくり返る（スマホを激しくランダムに動かす）
  • くらげ・桜の花びら・雪・泡・魚 … 「ゆらぎ」のあるものは何でも

4-2. センサデータ取得アプリの探し方

調査

アプリは 自分で探す ことが課題の一部．App Store / Google Play で「加速度センサ」「accelerometer」「sensor logger」などで検索し，CSV エクスポートできる ものを選ぶと楽．

選ぶときのチェックポイント

  • 無料で使えるか（または学生にとって許容範囲か）
  • 加速度・ジャイロなど 必要なセンサ が取れるか
  • 記録したデータを CSV / 表形式で書き出せる か（メール送信，AirDrop，クラウド保存などの手段）
  • サンプリングレート（1秒に何回記録するか）が選べるとなお良い
  • レビュー・運営元・プライバシーポリシーをざっと確認

個人情報・センサ取得時の注意

  • アプリのアクセス権限要求は内容を読んでから許可する
  • 動画や位置情報を 記録しないアプリ を選ぶと安心
  • 取得したセンサデータも 個人を特定できる情報 になり得る（歩行パターン等）．SNSに公開する場合は自分の身体情報が含まれていないか考える

※ 教員から特定のアプリを 推奨はしない ── 「自分で探して比較する」 という調査も学びの一部．

4-3. 進め方（推奨手順）

手順
  1. 作品のコンセプトを決める（先に絵を決める）．「何が」「どう動く」かをひと言で言えるようにする．
  2. 必要な動きの種類 を考える（ふわふわ／ガタガタ／円を描く／ジャンプ …）．それに合うセンサ操作を決める．
  3. アプリを探してインストール．試しに数秒記録 → CSV で取り出せるか確認する．
  4. 本番のデータを記録．長すぎず（30〜90秒程度）扱いやすい長さで．
  5. CSV を ~/MD1/no5/ など作業フォルダに置く．列名・行数を確認．
  6. opencode で py5 アニメを実装．センサ値 → 画面上の何かの動きにマッピング．必要なら 移動平均 で滑らかにする．
  7. 動きを観察 → コンセプトに合うようにパラメータ（窓幅・色・サイズ・スピード）を調整．
  8. 完成したら 画面録画（macOS: ⌘+Shift+5）で 10〜30秒の動画を作る．

📘 Task 1 口頭試問の答え

▶ Q1. 引数と戻り値

引数: name（呼び出し時に "Tanaka" が渡る）．戻り値: "Hello, " + name で作った文字列 "Hello, Tanaka"．

実行結果: Hello, Tanaka が表示される．

▶ Q2. 定義と呼び出し

コードA: say_hi() を 定義 しただけで 呼び出していない ため何も起きない．

コードB: 定義の下で say_hi() を 呼び出している ので関数の中身が実行され Hi! が表示される．

「定義」は関数のレシピを書くこと，「呼び出し」はそのレシピを実際に実行すること．

▶ Q3. デフォルト引数

x = 15（add(5) は b を省略 → デフォルト値 b=10 が使われる．5 + 10 = 15）

y = 25（add(5, 20) は b=20 を明示．5 + 20 = 25）

引数にデフォルト値があると 省略可能 になる．

▶ Q4. 関数のメリット
  • 重複を減らせる（DRY 原則）．同じ計算を1か所にまとめられる．
  • 修正が1か所 で済む（例: 税率が 10%→8% に変わっても add_tax 内だけ直せばよい）．
  • 名前で意味が分かる．add_tax(100) は読むだけで「税込価格を求める」と分かる．
  • テストや再利用 がしやすい．
▶ Q5. リストを処理する関数

何をする関数か: 渡されたリストの各要素を2倍にした新しいリストを返す．

  1. result = [] で空のリストを用意．
  2. for v in values で values から1つずつ取り出す（1→2→3）．
  3. 各 v に対して new_value = v * 2 を計算．
  4. result.append(new_value) で末尾に追加．
  5. ループ終了後に result を返す．

実行結果: [2, 4, 6]

▶ Q6. 複数引数（BMI）

引数: 2個． weight（体重 kg），height（身長 m）．

計算: 60 / (1.70 * 1.70) = 60 / 2.89 ≈ 20.76

my_bmi ≈ 20.76（おおよそ 20〜21 と答えられればOK）．

▶ Q7. 戻り値がない関数

result には None が入る． show_message は print しているだけで return が無い．Python では return が無い関数は自動で None を返す．

違い: 戻り値がある関数は 計算結果を呼び出し元に返す（変数に代入できる）．戻り値が無い関数は 動作だけが目的 で，値を受け取っても意味のあるデータは入らない．

▶ Q8. スコープ

result は 150 と表示される．その次の print(x) は NameError: name 'x' is not defined でエラー．

理由: x は calculate() の 中で定義されたローカル変数．関数を抜けると x は消える．関数の 外 からは見えない（これを スコープ と呼ぶ）．

▶ Q9. 関数の中から関数を呼ぶ
  1. add_three(1, 2, 3) を呼び出す．
  2. 中で add(1, 2) が呼ばれて first = 3．
  3. 次に add(3, 3) が呼ばれて total = 6．
  4. return total で 6 を返す．

最終的な値: 6

▶ Q10. average(a, b) の解答例 
Python ── Q10 解答例
def average(a, b):
    total = a + b
    answer = total / 2
    return answer

result = average(10, 20)
print(result)  # → 15.0

口頭で「def から始めて関数名と引数」「足す」「2で割る」「return」の4つが言えていれば正解．
