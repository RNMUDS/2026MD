① 変数：値に名前をつけて覚えておく箱

JavaScript
const color = 'tomato';   // const = あとで変えない値
let count = 0;          // let = あとで変える値
count = count + 1;        // count を 1 増やす
console.log(color);     // → tomato（コンソールで確認）
console.log(count);     // → 1
  • const＝定数（中身を変えない）／let＝変数（中身を変える）
  • = は「等しい」ではなく「右の値を左に入れる」という意味
変数はラベルを貼った箱。const color = 'tomato' ＝「color という箱に tomato を入れる」。あとは color と書けば中身を取り出せる。

② データ型：値には種類がある

データサイエンスでは「これは数値か、文字か、はい/いいえか」を意識するのが超重要。JavaScriptの基本3種類。

JavaScript
console.log(42);          // 数値（Number）→ クォートなし。計算できる
console.log('skyblue');   // 文字列（String）→ クォート '　' で囲む
console.log(true);        // 真偽値（Boolean）→ true / false の2択
型例図形では何に使う？
数値0.6 -5 3.14位置・大きさ・角度・色相
文字列'tomato' 'a-box'色名・図形の種類
真偽値true false「偶数か？」などの条件の結果

③ 配列：値を「並べて」持つ（データ列の正体）

配列＝同じ仲間の値を順番に並べた箱。色のリスト、点数のリスト、ログの時系列…みんな配列。

JavaScript
const colors = ['tomato', 'skyblue', 'gold', 'violet'];

console.log(colors[0]);       // → tomato（先頭は 0 番から数える！）
console.log(colors[2]);       // → gold
console.log(colors.length);   // → 4（要素の個数）
  • 番号（インデックス）は 0 から。1番目＝[0]、2番目＝[1]
  • colors[i % colors.length]＝i が増えても色がぐるぐる循環する書き方（今日よく使う）

データサイエンスとのつながり

配列は 表の1列（カラム）そのもの。例：scores = [3, 4, 5, 4, 2] ＝ アンケートの回答列。第13回で平均や検定を計算するのも、この配列。

④ オブジェクト：1件の情報を「まとめて」持つ（1レコードの正体）

オブジェクト＝名前つきの値をまとめた箱。「1個の図形」や「1人の回答」のような1件分のデータを表す。

JavaScript
// 図形1個ぶんのデータ
const shape = { x: 1, y: 1, z: -3, color: 'gold' };

console.log(shape.x);       // → 1（ドットで取り出す）
console.log(shape.color);   // → gold
名簿の1行と同じ。{ 名前: '太郎', 点数: 80 } のように、見出し（キー）と値がセット。配列が「列」なら、オブジェクトは「1行」。
図解：配列 × オブジェクト ＝ データテーブル（＝後の回の「ログ」）

オブジェクト（1行）を、配列（並べる）で束ねると、表（テーブル）になる。これがCSVやログデータの正体。

JavaScript
const shapes = [
  { x: -1, y: 1, z: -3, color: 'tomato'  },   // 1件目
  { x:  0, y: 1, z: -3, color: 'skyblue' },   // 2件目
  { x:  1, y: 1, z: -3, color: 'gold'    },   // 3件目
];

⑤ if：条件で処理を分ける

「もし〜なら A、そうでなければ B」。条件A/B の切りかえや、しきい値の判定に使う基本。

JavaScript
if (i % 2 === 0) {
  color = 'gold';       // i が偶数のとき
} else {
  color = 'skyblue';    // それ以外（奇数）のとき
}
  • i % 2＝「i を 2 で割ったあまり」。0なら偶数、1なら奇数
  • ===＝「等しいか？」を調べる（結果は true/false ＝ ②の真偽値）
  • 他に >（より大きい）<（より小さい）>=（以上）<=（以下）も使える

⑥ 関数：処理に名前をつけて、何度でも使う「道具」

同じ処理を毎回書くのは大変。処理に名前をつけて道具化すると、呼ぶだけで使える。

JavaScript
// 「あいさつする」道具を作る（定義）
function greet(name) {
  console.log(`こんにちは、${name}さん`);
}

greet('みな');   // 使う（呼び出し）→ こんにちは、みなさん
greet('太郎');   // 何度でも呼べる → こんにちは、太郎さん
  • function 名前(引数) { 処理 } で道具を作る
  • 引数（ひきすう）＝道具に渡す材料。name の中身が処理に差しこまれる
  • 今日は「図形を1つ描く」道具（drawShape）を作って使う

⑦ Math：計算の道具箱（アートの心臓部）

Math は最初から用意された計算の道具箱。円・らせん・ランダムな散らばりは、ここから生まれる。

JavaScript
console.log(Math.random());          // 0以上1未満のランダムな数（毎回ちがう）
console.log(Math.random() * 10);     // 0〜10 のランダムな数
console.log(Math.sin(Math.PI / 2));  // サイン（角度を渡す）→ 1
console.log(Math.cos(0));            // コサイン（角度を渡す）→ 1
console.log(Math.PI);               // 円周率 3.14159...（1周＝2 * Math.PI）

円の描き方の「魔法の公式」（std2-3で使う）

角度を 0 から 1周（2π） まで動かしながら、

  • x ＝ Math.cos(角度) * 半径
  • z ＝ Math.sin(角度) * 半径
  • この2つを位置にすると、図形がきれいな円に並ぶ

JavaScriptで図形を描く道具（3手順）

図形を1つ描くのは、たった3ステップ

  • ① 作る：document.createElement('a-box') で図形を1つ生成
  • ② 設定する：図形.setAttribute('属性', 値) で位置・色・大きさを指定
  • ③ 入れる：group.appendChild(図形) で3D空間に追加

3ステップを1つにまとめる（まず手で1個）

ひな形の <script>（group 取得の次）にこれを書くと、金色の箱が1つ出る。

JavaScript
const box = document.createElement('a-box');   // ① 作る
box.setAttribute('position', '0 1 -3');             // ② 位置
box.setAttribute('color', 'gold');                  // ② 色
group.appendChild(box);                            // ③ 空間に追加

保存 → ブラウザ再読み込み。正面の少し奥に金色の箱が見えれば成功。

道具化：1個描く処理を「関数」にする（今日の主役）

毎回4行書くのは大変。「図形を1つ描く道具 drawShape」を作っておくと、1行で何個でも描ける。今日の課題はこの道具を使い倒す。

JavaScript
// 種類・位置・色・大きさを渡すと、図形を1つ描く道具
function drawShape(type, x, y, z, color, size) {
  const el = document.createElement(type);
  el.setAttribute('position', `${x} ${y} ${z}`);
  el.setAttribute('color', color);
  el.setAttribute('scale', `${size} ${size} ${size}`);
  group.appendChild(el);
}

// 使い方：1行で1個描ける！
drawShape('a-box', 0, 1, -3, 'gold', 1);
drawShape('a-sphere', 2, 1, -3, 'tomato', 0.6);
  • type＝図形の種類（'a-box' 'a-sphere' 'a-cylinder' 'a-cone' 'a-torus'）
  • scale＝拡大率。1 がもとの大きさ、0.5 で半分、2 で2倍（どの図形にも使える）
  • あとは for 文の中で drawShape(...) を呼ぶだけで、図形が量産できる

この道具を for と組み合わせると…

JavaScript
for (let i = 0; i < 8; i++) {
  drawShape('a-box', i - 4, 1, -5, 'gold', 0.6);
}
// → 金色の箱が横に8個ならぶ（第1回のfor文と同じ仕組み）

イベント：図形を〇で狙って触る（操作を受け取る）

ここからが「データを取る環境」の入口（STEP 2）

  • これまでは図形を「描く・見る」だけ。ここからは図形を「触る（クリック）」
  • クリックはイベント＝ユーザの操作。プログラムで受け取れる
  • 受け取った操作を記録すれば操作ログになる（＝後の回でデータを集める仕組みの土台）

まず：画面の中央に〇（黒丸）カーソルを出す

イベントの前に、まず「触る道具」を画面に出す。<a-camera>（自分の視点）の中に <a-cursor> を入れると、画面の中央にいつも〇（黒丸）が表示される。

HTML
<!-- a-scene の中に書く -->

  <a-cursor color="black"></a-cursor>   <!-- 画面の中央に出る黒い〇 -->
</a-camera>
  • <a-cursor>＝視点の中央にいつも出る〇（照準）。視点を回しても、つねに画面の真ん中にある
  • color="black" で黒丸にする（背景が暗くて見えにくいときは "white" でもよい）
  • この〇が、3D空間の図形を「指す・触る」道具になる

※ いまはまだ、〇を重ねてクリックしても何も起きない。次に、この〇で図形に触れる仕組みを学ぶ。

仕組み：その〇から「見えない光線」が前にのびている

  • 中央の〇（黒丸）から、まっすぐ前へ見えない光線（レイ）がのびている
  • 視点を動かして〇をオブジェクトに重ねると、光線がそのオブジェクトに当たる
  • 当たった状態でクリックすると、そのオブジェクトに 'click' イベントが起きる
レーザーポインターで的を狙うのと同じ。画面中央の〇が照準。〇を的（図形）に合わせて押す、という操作。視点はドラッグ（マウスで画面を動かす）で回せる。

イベントとは ─ 「何かが起きた合図」

  • クリック・マウス移動・キー入力・選択… ユーザの操作はすべてイベントとして発生する
  • イベントを聞く係（リスナー）を登録しておくと、起きた瞬間に処理が動く
  • 「いつ・何が起きたか」を順番に書き出すと、それが時系列データ（ログ）になる
玄関のチャイムと同じ。「押されたら鳴る」とあらかじめ決めておく（リスナー登録）と、訪問（イベント）のたびに反応する。誰がいつ来たかをメモすれば来客ログになる。

イベントを聞く基本：addEventListener

「この要素がクリックされたら、この処理をして」を登録する命令。形を覚えるだけでよい。

JavaScript

  // クリックされた“瞬間”に、ここが動く
  console.log('クリックされた！');
});
  • 'click'＝聞きたいイベントの名前（他に 'mouseenter' 等）
  • function () { ... }＝起きたときに動かす処理（⑥関数の仲間）

まず仕組みだけを試す完成HTML（A-Frame不要・ボタンで体験）

標準課題 std2-5：クリックしたら色が変わる ─ 完成コードを動かして「応用」する

まず下の完成コードをそのままコピーして動かす。〇を図形に重ねてクリックすると、その図形の色がランダムに変わる。仕組みを理解したら、後半の応用課題（必須）＝「4つの要件をすべて満たす index.html を1つ作る」に取り組む。

完成コード（index.html として保存 → 開く → 〇を図形に重ねてクリック）

HTML
<!DOCTYPE html>
<html>
  <head>
    <script src="https://aframe.io/releases/1.6.0/aframe.min.js"></script>
  </head>
  <body>
    <a-scene>
      <a-sky color="#111"></a-sky>
      <a-plane rotation="-90 0 0" width="30" height="30" color="#1a1a1a"></a-plane>
      <!-- 画面中央に〇（黒丸）カーソルを出す（カメラの中に入れる） -->
      <a-camera>
        <a-cursor color="black" raycaster="objects: .clickable"></a-cursor>
      </a-camera>
      <a-entity id="group"></a-entity>
    </a-scene>

    <script>
      const group = document.querySelector('#group');

      // 図形を1つ作る。クリックすると色がランダムに変わる
      function drawClickable(type, x, y, z, color) {
        const el = document.createElement(type);
        el.setAttribute('position', `${x} ${y} ${z}`);
        el.setAttribute('color', color);
        el.classList.add('clickable');          // 〇の狙う対象にする
        el.addEventListener('click', function () {  // クリックされたら…
          const hue = Math.random() * 360;
          el.setAttribute('color', `hsl(${hue}, 80%, 60%)`);  // 色を変える
        });
        group.appendChild(el);
      }

      // 箱を8個ならべる
      for (let i = 0; i < 8; i++) {
        drawClickable('a-box', i - 4, 1.5, -4, 'gray');
      }
    </script>
  </body>
</html>

コードの読みどころ（クリックで色が変わる仕組み）

  • el.classList.add('clickable')＝この図形を〇の狙う対象にする（準備②）
  • el.addEventListener('click', function () { ... })＝クリックされた瞬間に { } の中が動く
  • Math.random() * 360 で色相を作り、setAttribute('color', ...) で色を変える
  • まずコピーして保存 → 開く → 視点をドラッグで回し、〇を箱に重ねてクリック → 色が変われば成功

応用課題（必須）：次の4つをすべて満たす index.html を1つ新しく作る

上の完成コードをもとに、1つの新しいファイルを作り、その中に下の4つの要件をすべて盛り込む。

  • 要件1：図形を for 文で10個以上ならべる（形は自由：a-box / a-sphere など）
  • 要件2：図形を〇で重ねてクリックすると色が変わる（変えた色はそのまま残る）
  • 要件3：〇を重ねた瞬間（mouseenter）に大きくなる（scale を大きく）
  • 要件4：〇が離れた瞬間（mouseleave）に元の大きさにもどる

※ mouseenter / mouseleave は公式ドキュメントの cursor イベント（上の📖参照）。1つの drawClickable 関数の中に、click・mouseenter・mouseleave の3つの addEventListenerを書くのがコツ。

ヒント：要件2〜4を1つの関数にまとめる書き方

完成コードの drawClickable の中（addEventListener('click', …) の行）を、次の3つにする。要件1は for の回数を10以上にすればよい。

JavaScript
// 要件2：クリックすると色が変わる（色は残る）
el.addEventListener('click', function () {
  const hue = Math.random() * 360;
  el.setAttribute('color', `hsl(${hue}, 80%, 60%)`);
});
// 要件3：〇を重ねた瞬間に大きくする
el.addEventListener('mouseenter', function () {
  el.setAttribute('scale', '1.5 1.5 1.5');
});
// 要件4：〇が離れたら元の大きさにもどす
el.addEventListener('mouseleave', function () {
  el.setAttribute('scale', '1 1 1');
});

これを drawClickable の中（group.appendChild(el) の前）に入れる。要件1は for (let i = 0; i < 10; i++) のように回数を10以上に。

  • 何を・どう記録するかを自分で考えて、見出しや表を作って構成する
  • 「見やすく整理する」こと自体が、データを扱う練習になる

1つのファイルにまとめて提出

  • 穴埋め（第1回の復習・JavaScript基礎・イベント）＋ std2-1〜std2-5 のコードとスクショを1つのNotionページに集約
  • PDFにエクスポート → Google Classroomに PDF 1ファイル
  • 上部に「グループ番号・氏名・第2回」を明記

記録のコツ

  • 穴埋めは「答え」＋なぜそうなるかを一言
  • 課題はコード全文＋実行画面のスクショをセットで貼る
  • 「数値を変えたら見た目がどう変わったか」を1行メモすると、理解が深まる
